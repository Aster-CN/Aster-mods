# net_read —— 联网读取 MOD（实验）

Aster 的第一个 MOD：把网页变成一段**可信、可筛、可回查**的上下文，回答仍由主体的后端模型完成。

默认关闭。启用：设置 → MOD 管理 → 选中 `net_read` → 启用。

## 用法

| 方式 | 示例 |
|---|---|
| 消息带链接，自动读取 | `https://example.com/news 这篇文章讲了什么？` |
| 问实时信息，自动搜索 | `看看今天的新闻`、`今天天气怎么样` |
| 指令：读网页 | `/联网：https://example.com/news 这篇文章讲了什么？` |
| 指令：搜索 | `/搜索：量子计算最新进展` |
| 只概括 | `/联网：https://example.com/news` |

## 四步流水线

1. **读取**：抓文本类页面，剥掉脚本 / 样式 / 导航 / 页脚，按 charset 解码；
2. **筛选**：按提问的 2-gram 重合度挑句子，超预算截断（标 `……（后略）`）；
3. **整合**：包成「外部网页资料」块，正文里的提示注入行整行屏蔽；
4. **输出**：主模型只依据资料回答，末尾标 `来源：链接`。

## 搜索（v0.2.0）

- 触发词：`新闻 / 最新 / 热搜 / 实时 / 天气 / 股价 / 汇率 / 比分 / 行情 / 发布会 / 政策 / 搜一下 / 查一下` 等；
- 不触发：`今天有点累` 这种情绪句（单独的"今天"不算）；
- 取前 5 条结果的标题 + 链接 + 摘要，必要时再读首条正文；
- 走 `cn.bing.com` 公开结果页 HTML，不需要 Key；解析不到就返回"没搜到"，不编。

## 边界

- 不做搜索引擎、不渲染 JS、不绕验证码；
- 403 / 验证页 / 纯 JS 页只报原因，不重试轰炸；
- 只读 `http/https` 公网地址，内网与本机地址一律拒绝（SSRF 防护）。

## 参数

`manifest.json` 的 `settings`，可被 `aster_soul.json` → `mods.settings.net_read` 覆盖：

| 参数 | 默认 | 说明 |
|---|---|---|
| `timeout` | 15 | 请求超时（秒） |
| `max_bytes` | 800000 | 最多读多少字节 |
| `max_chars` | 6000 | 注入字数上限 |
| `auto_url` | true | 消息带链接时自动读取 |
| `lead_sentences` | 3 | 命中不足时回退的前几句 |

规范见仓库 [`docs/mod.md`](../../docs/mod.md) 与 [`docs/net.md`](../../docs/net.md)。
